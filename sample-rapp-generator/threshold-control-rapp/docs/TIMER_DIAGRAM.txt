THREAD ARCHITECTURE:
====================

Main Thread:
  │
  ├─► Monitoring Loop (runs every 30s)
  │   ├─► Query InfluxDB
  │   ├─► Evaluate Thresholds
  │   └─► Start Timers if needed
  │
  └─► Flask Health Server (port 8080)

Background Timer Threads (one per equipment):
  │
  ├─► Timer Thread for gNB-001 (60s countdown)
  │   └─► Calls turn_on_equipment('gNB-001') when expires
  │
  ├─► Timer Thread for gNB-002 (60s countdown)
  │   └─► Calls turn_on_equipment('gNB-002') when expires
  │
  └─► Timer Thread for gNB-003 (60s countdown)
      └─► Calls turn_on_equipment('gNB-003') when expires

All threads share equipment_states dict (protected by lock)


KEY IMPLEMENTATION DETAILS:
============================

1. Timer Creation:
   threading.Timer(60, self.turn_on_equipment, args=['gNB-001']).start()
   
2. State Tracking:
   equipment_states['gNB-001'] = {
       'state': 'off',
       'timer': datetime(2026, 1, 20, 14, 31, 15),
       'reason': 'Threshold exceeded: DRB.MaxActiveUeDl=10'
   }

3. Thread Safety:
   with self.state_lock:
       # Only one thread can access equipment_states at a time
       current_state = self.equipment_states.get(equipment_id)

4. No Re-triggering:
   if threshold_exceeded and current_state['state'] == 'on':
       # Only act if equipment is currently ON
       # If already OFF, do nothing (timer is running)
